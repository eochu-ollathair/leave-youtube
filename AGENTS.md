# Help someone get Leave YouTube working

If a person gives you this project and asks you to set it up, do the setup with them. Read `README.md` and `START_HERE.md` first. The person does not need the original maker's computer, AI, Telegram account or passwords.

1. Use a Mac or Linux computer with Python 3.10 or newer. Run `python3 start.py` from this folder. The starter installs what the program needs and opens its private settings page. There is no tested Windows starter yet; say that plainly.
2. If the person has no Telegram bot, help them create one with BotFather. The starter finds their own chat after they message the bot. Keep their bot code, page key and settings on their computer. Never put them in GitHub or in a public answer.
3. Let them choose subjects, a number of videos for each subject, creators to include and creators to block. Check a real video selection and make a preview from readable speech. Do not claim that a video without readable speech was summarised.
4. If they want explanations of why claims matter or a sceptical angle, connect a text AI they control. The free version quotes speech and cannot reliably infer a hidden motive. Mark unproven motives as possibilities.
5. When they ask to send, check that Telegram accepted the message. Sent videos must disappear from the chosen list and must not appear in later reports. Turn on morning delivery only when they want it, and check that the next scheduled send is actually due.
6. Check Telegram replies: “kill that YouTube” blocks a creator when the replied-to report has exactly one; with several creators, the program asks for a name. “add YouTube [creator]” adds a creator, and “add subject [name]” adds a subject. If Leave the Podcasts runs beside this project using the same bot, one reply listener handles both.

The working result is a real preview, a private settings page the person can reopen, and a Telegram report when requested. Report any missing speech or service failure plainly.
